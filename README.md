# CHIP-8 Emulator
## Requirments
1. Python 3
2. Pygame Library

## About CHIP-8 Emulator
CHIP-8 Emulator is python based program that emulates CHIP-8 binaries. It may include bugs, so use it at your own risk.

## Usage
### Running the Emulator
1. Clone the github repo  
'''console
git clone https://github.com/JUSY5696/CHIP-8.git
'''
2. Change the directory to the repo<br>
`cd CHIP-8`
3. Run the program<br>
`python3 CHIP_8_Emu.py`
### Creating the ROM
1. Inside the repo, open ch8Creator.py
2. Fill in the binarray.
3. Save, and run ch8Creator.py<br>
`python3 ch8Creator.py`
